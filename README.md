# Warcraft III Tools Source

Source-only repository for the Warcraft III trainer, hotkey tool, and selection-limit tool.

This repository intentionally contains source code, build specifications, version data, tests, and the small icon assets required by the build specifications. It does not contain packaged EXEs/DLLs, logs, screenshots, reverse-engineering dumps, game files, user data, or deployment files. Native binaries must be built locally from the checked-in C sources.

## Components

- `war3_reforged_trainer.py`: trainer application and its protocol/service modules.
- `war3_hotkey_tool.py`: hotkey application, adapters, transport, and native helper sources.
- `war3_selection_limit_tool.py`: selection-limit application and native helper sources.
- `versions/`: source-only snapshots for historical tool tags plus the current working source snapshot.
- `tools/`: native sources, version profiles, bridge headers, and build helpers.

The version names under `versions/` refer to the tool being maintained. They are not Warcraft III game versions. Game build compatibility is represented separately by `profiles/*.json` and `hotkey_profiles/*.json`.

## Build prerequisites

- Windows 10/11 x64.
- Python 3.11 or newer with PyInstaller and the Python packages imported by the selected component.
- Visual Studio 2022 x64 build tools for the selection-limit helper and MSVC-based native builds.
- LLVM/Clang with the Windows target for the hotkey bridge build.
- The Warcraft III installation is only needed when running the built tools; it is not part of this repository.

## Build notes

Build from the repository root. The existing `.spec` files describe the packaged applications. Native helper DLLs are inputs to some specs and are generated by the corresponding scripts under `tools/`; generated output is intentionally ignored by Git.

Before building a release, run the relevant unit tests and verify that the generated bridge/profile files match the selected game profile. A source checkout does not claim compatibility with an unlisted game build until that build has passed the repository's version-identification and capability checks.

## Version layout

The root source is the current working source selected for publication. The same source-only tree is also archived at `versions/current-20261001/` so the latest worktree state has an explicit snapshot. Historical source snapshots are under `versions/`; see `VERSION_SOURCE_MAP.md` for the tag-to-snapshot mapping. Versioned source is kept for inspection and reproducible maintenance, not as a promise that every historical build remains compatible with current game binaries.

## Publication boundary

Do not add runtime logs, user-provided files, game assets, packaged binaries, memory dumps, screenshots, or reverse-engineering work products to this repository. Put those in a separate private case directory when needed for debugging.
