# Current Source Snapshot

This directory is the explicit source snapshot of the latest worktree state used for the repository publication on 2026-10-01.

It contains source and build inputs for:

- the Warcraft III trainer;
- the hotkey tool, including the current adapter and transport modules;
- the selection-limit tool;
- native C/header sources, build helpers, specifications, tests, icons, and current game-build profile data.

`3.0.0.24268` in the profile files is a Warcraft III game build identifier. It is not the version number of the trainer executable.

Packaged executables, DLLs, logs, screenshots, game files, memory dumps, reverse-engineering work products, and user data are intentionally excluded.
